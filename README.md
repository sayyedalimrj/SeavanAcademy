# آکادمی سیوان | Seavan Academy
سامانه آموزش داخلی شرکت بر پایه Moodle 4.5.16 LTS. زبان پیش‌فرض فارسی (RTL)، بدون ثبت‌نام عمومی.

## راه‌اندازی ویندوز
1. Docker Desktop با موتور WSL2 نصب و اجرا شود (شرایط مجوز Docker Desktop را برای شرکت بررسی کنید).
2. مخزن را Clone یا ZIP کنید. در پوشه پروژه فایل START.cmd را اجرا کنید.
3. آدرس IP ثابت لپ‌تاپ در شبکه داخلی را وارد کنید؛ برای آزمایش فقط روی لپ‌تاپ، 127.0.0.1 را وارد کنید. آدرس به صورت http://IP:8080 خواهد بود.
4. رمز مدیر در اولین راه‌اندازی تولید و نمایش داده می‌شود و در .env محلی می‌ماند.
5. پس از نصب، با کاربر admin وارد شوید. از مدیریت سایت، کاربران، دسته‌بندی دوره‌ها، ثبت‌نام دستی کاربران و گزارش‌ها را مدیریت کنید.

برای شبکه داخلی، IP را با DHCP reservation ثابت کنید و در Windows Firewall فقط شبکه Private و محدوده مجاز را اجازه دهید. هیچ port forwarding اینترنتی ایجاد نکنید. پیش از استفاده واقعی از حساب‌های کارکنان، HTTPS با گواهی مورد اعتماد شبکه تنظیم شود؛ حالت اولیه HTTP فقط برای آزمایش است.

## نگهداری
- START.cmd: ساخت و اجرا؛ اجرای دوباره داده‌ها را پاک نمی‌کند.
- STOP.cmd: توقف بدون حذف داده‌ها.
- STATUS.cmd: وضعیت سرویس‌ها.
- داده‌ها و فیلم‌ها در volume مستقل و دیتابیس داخلی هستند، نه در GitHub. برای ظرفیت دیسک، محل disk image Docker را تنظیم کنید.
- برای بکاپ، ابتدا سرویس web و cron را متوقف و dump دیتابیس و کپی volume moodledata را روی دیسک جدا ذخیره کنید؛ قبل از بهره‌برداری بازیابی را تست کنید.
- پوشه moodle/ در صورت import شامل سورس رسمی است؛ Dockerfile از آن استفاده می‌کند، یا در نبود آن نسخه رسمی را با SHA256 می‌گیرد.
- ترجمه رسمی فارسی ناقص است؛ زبان انگلیسی fallback هسته است. ترجمه‌های تکمیلی باید در fa_local یا افزونه مستقل باشند.
- مدیریت دسترسی، گزارش ورود، آزمون و تکمیل فعالیت در هسته موجود است؛ درصد واقعی تماشای ویدئو و گواهی اختصاصی نیازمند افزونه و تست است.
- نسخه 4.5 تا اکتبر 2027 وصله امنیتی دریافت می‌کند؛ پیش از پایان پشتیبانی ارتقا دهید.
- فقط دوره‌هایی با مجوز آموزش سازمانی بارگذاری شوند.

## منبع و مجوز
Moodle GPLv3+، https://github.com/moodle/moodle — فایل‌های مجوز و حق مؤلف اصلی حفظ می‌شوند.

## نسخه اختصاصی سیوان
- `moodle/theme/seavan/`: قالب مستقل مبتنی بر Boost، راست‌چین و قابل ارتقا.
- `moodle/local/seavan/`: صفحه واقعی آکادمی، دوره‌های اختصاص‌یافته، جست‌وجو، پیشرفت بر مبنای تکمیل فعالیت و میانبرهای مدیریتی متناسب با مجوز کاربر.
- مشاهده دوره: از امکانات اصلی Moodle استفاده می‌شود. ثبت پیشرفت فعالیت معادل زمان واقعی تماشای فیلم نیست.
- برای فونت ایران‌سنس وب، نسخه دارای مجوز شرکت را با نام‌های `IRANSansWeb.woff2` و `IRANSansWeb_Bold.woff2` در مسیر محلی `moodle/theme/seavan/fonts/` قرار دهید؛ فایل‌ها در گیت نادیده گرفته می‌شوند. سپس START.cmd را اجرا و کش قالب را پاک کنید. در نبود فایل، فونت نصب‌شده یا Tahoma جایگزین می‌شود.
- پیش‌نمایش واقعی با GitHub Codespaces اجرا می‌شود، نه HTML شبیه‌سازی‌شده.
- GitHub Pages صرفاً راهنمای راه‌اندازی است و خود Moodle را اجرا نمی‌کند.

## اجرای واقعی روی GitHub Codespaces
[ایجاد Codespace](https://github.com/codespaces/new?hide_repo_select=true&repo=1471423154&ref=main). پس از تکمیل postCreateCommand، پورت 8080 را در تب Ports باز کنید (Private). نام کاربری admin و رمز اولیه در فایل .env محلی است. اگر اجرا نشد، در ترمینال `bash .devcontainer/start-moodle.sh` را اجرا کنید. Codespaces سهمیه و هزینه احتمالی دارد؛ بعد از تست متوقفش کنید. داده واقعی شرکت را در آن وارد نکنید.
