# آکادمی سیوان | Seavan Academy
سامانه آموزش داخلی شرکت بر پایه Moodle 4.5.16 LTS. زبان پیش‌فرض فارسی (RTL)، بدون ثبت‌نام عمومی. [راهنمای تحویل و راه‌اندازی نسخه ۱٫۰](docs/company-fa.md).

## راه‌اندازی ویندوز
1. Docker Desktop با موتور WSL2 نصب و اجرا شود (شرایط مجوز Docker Desktop را برای شرکت بررسی کنید).
2. مخزن را Clone یا ZIP کنید. در پوشه پروژه فایل START.cmd را اجرا کنید.
3. آدرس IP ثابت لپ‌تاپ در شبکه داخلی را وارد کنید؛ برای آزمایش فقط روی لپ‌تاپ، 127.0.0.1 را وارد کنید. آدرس به صورت http://IP:8080 خواهد بود.
4. رمز مدیر در اولین راه‌اندازی تولید و نمایش داده می‌شود و در .env محلی می‌ماند.
5. پس از نصب، با کاربر admin وارد شوید. از مدیریت سایت، کاربران، دسته‌بندی دوره‌ها، ثبت‌نام دستی کاربران و گزارش‌ها را مدیریت کنید.

برای شبکه داخلی، IP را با DHCP reservation ثابت کنید و در Windows Firewall فقط شبکه Private و محدوده مجاز را اجازه دهید. هیچ port forwarding اینترنتی ایجاد نکنید. پیش از استفاده واقعی از حساب‌های کارکنان، HTTPS با گواهی مورد اعتماد شبکه تنظیم شود؛ حالت اولیه HTTP فقط برای آزمایش است.

## نگهداری
- START.cmd: ساخت و اجرا؛ اجرای دوباره داده‌ها را پاک نمی‌کند.
- STOP.cmd: توقف بدون حذف داده‌ها.
- STATUS.cmd: وضعیت سرویس‌ها.
- داده‌ها و فیلم‌ها در volume مستقل و دیتابیس داخلی هستند، نه در GitHub. برای ظرفیت دیسک، محل disk image Docker را تنظیم کنید.
- برای بکاپ، ابتدا سرویس web و cron را متوقف و dump دیتابیس و کپی volume moodledata را روی دیسک جدا ذخیره کنید؛ قبل از بهره‌برداری بازیابی را تست کنید.
- پوشه moodle/ در صورت import شامل سورس رسمی است؛ Dockerfile از آن استفاده می‌کند، یا در نبود آن نسخه رسمی را با SHA256 می‌گیرد.
- ترجمه رسمی فارسی ناقص است؛ زبان انگلیسی fallback هسته است. ترجمه‌های تکمیلی باید در fa_local یا افزونه مستقل باشند.
- مدیریت دسترسی، گزارش ورود، آزمون و تکمیل فعالیت در هسته موجود است؛ درصد واقعی تماشای ویدئو و گواهی اختصاصی نیازمند افزونه و تست است.
- نسخه 4.5 تا اکتبر 2027 وصله امنیتی دریافت می‌کند؛ پیش از پایان پشتیبانی ارتقا دهید.
- فقط دوره‌هایی با مجوز آموزش سازمانی بارگذاری شوند.

## منبع و مجوز
Moodle GPLv3+، https://github.com/moodle/moodle — فایل‌های مجوز و حق مؤلف اصلی حفظ می‌شوند.

## نسخه اختصاصی سیوان
- `moodle/theme/seavan/`: قالب مستقل مبتنی بر Boost، راست‌چین و قابل ارتقا.
- `moodle/local/seavan/`: صفحه واقعی آکادمی، دوره‌های اختصاص‌یافته، جست‌وجو، پیشرفت بر مبنای تکمیل فعالیت و میانبرهای مدیریتی متناسب با مجوز کاربر.
- مشاهده دوره: از امکانات اصلی Moodle استفاده می‌شود. ثبت پیشرفت فعالیت معادل زمان واقعی تماشای فیلم نیست.
- برای فونت ایران‌سنس وب، نسخه دارای مجوز شرکت را با نام‌های `IRANSansWeb.woff2` و `IRANSansWeb_Bold.woff2` در مسیر محلی `moodle/theme/seavan/fonts/` قرار دهید؛ فایل‌ها در گیت نادیده گرفته می‌شوند. سپس START.cmd را اجرا و کش قالب را پاک کنید. در نبود فایل، فونت نصب‌شده یا Tahoma جایگزین می‌شود.
- پیش‌نمایش واقعی با GitHub Codespaces اجرا می‌شود، نه HTML شبیه‌سازی‌شده.
- اجرای سازمانی با Docker Compose روی سرور شرکت انجام می‌شود.

## اجرای واقعی روی GitHub Codespaces
[ایجاد Codespace](https://github.com/codespaces/new?hide_repo_select=true&repo=1471423154&ref=main). پس از تکمیل postCreateCommand، پورت 8080 را در تب Ports باز کنید (Private). نام کاربری admin و رمز اولیه در فایل .env محلی است. اگر اجرا نشد، در ترمینال `bash .devcontainer/start-moodle.sh` را اجرا کنید. Codespaces سهمیه و هزینه احتمالی دارد؛ بعد از تست متوقفش کنید. داده واقعی شرکت را در آن وارد نکنید.

## نسخه ۰.۲ — آموزش ساده
- خانه: ادامه دوره‌های ثبت‌نام‌شده به ترتیب آخرین مراجعه، پیشرفت تکمیل فعالیت و دسترسی سریع.
- کتابخانه: دوره‌های مجاز برای مشاهده در Moodle، جست‌وجوی عنوان، فیلتر دسته‌بندی و کاور واقعی دوره. ثبت‌نام بر اساس روش انتخاب‌شده برای همان دوره (دستی، گروهی یا خودثبت‌نام) است.
- مدیریت: ایجاد حساب، ورود گروهی CSV، دسته‌بندی، شرکت‌کنندگان، تنظیمات و گزارش. هیچ قفل تماشا، آزمون اجباری یا محدودیت اضافی اضافه نشده است.
- فونت: از خانه آکادمی > مدیریت > ظاهر و فونت، دو فایل دارای مجوز WOFF2/WOFF ایران‌سنس را بارگذاری کنید. فایل در Moodledata می‌ماند و کش به‌روزرسانی می‌شود. در صورت نبود فایل، فونت محلی یا Tahoma استفاده خواهد شد.
- دسته‌بندی‌های اولیه برای نصب جدید (بدون ساخت کاربران یا دوره‌های جعلی): دفتر فنی، اجرا، نرم‌افزار، مالی، ایمنی، مهارت فردی و آشنایی با شرکت. برای نصب موجود، در صورت تمایل:
  `docker compose exec -T --user www-data web php /var/www/html/local/seavan/cli/setup_categories.php`
- به‌روزرسانی نصب موجود پس از پایان نصب جاری: ابتدا از دیتابیس و Moodledata پشتیبان بگیرید؛ سپس `git pull --ff-only && docker compose up -d --build`. از `down -v` در محیط واقعی استفاده نکنید.
- گزارش‌ها و صفحات اصلی از امکانات واقعی Moodle هستند. ترجمه بسته رسمی فارسی هنوز تمام رشته‌های هسته و افزونه‌ها را پوشش نمی‌دهد. پیشرفت جلسات به معنای زمان تماشای واقعی نیست.

## به‌روزرسانی سریع محیط آزمایشی Codespaces
پس از اجرای موفق اولیه، `git pull --ff-only && bash .devcontainer/update-moodle.sh` قالب و افزونه‌های اختصاصی را در کانتینر موجود اعمال می‌کند؛ دیتابیس حذف نمی‌شود. این روش فقط برای پیش‌نمایش توسعه است؛ برای انتشار نهایی تصویر Docker را بازسازی کنید. رمز اولیه را فقط در ترمینال خصوصی با `grep '^ADMIN_PASSWORD=' .env | cut -d= -f2-` مشاهده کنید.
فونت جایگزین وزیرمتن از نسخه v33.003 با مجوز OFL گرفته می‌شود و روی سرور محلی قرار می‌گیرد. ایران‌سنس دارای مجوز از تنظیمات قالب اولویت دارد. در صورت عدم دسترسی به منبع فونت، Tahoma جایگزین است.

## نسخه ۰.۳ — هویت بصری سیوان
- لوگوی شرکت در قالب واقعی Moodle، صفحه ورود و منوی اصلی قرار گرفت. رنگ اصلی سرمه‌ای #173559 و رنگ تأکیدی طلایی #FCAF17 است.
- فایل‌های دارای مجوز ایران‌سنس در مخزن عمومی قرار نمی‌گیرند. برای استفاده از فونت ارسالی، در پنل مدیریت آکادمی > ظاهر و فونت، IRANSansWeb.woff2 را به عنوان وزن معمولی بارگذاری کنید. وزن ضخیم جداگانه اختیاری است. همچنین می‌توان فایل را در مسیر محلی moodle/theme/seavan/fonts/IRANSansWeb.woff2 قرار داد و اسکریپت به‌روزرسانی را اجرا کرد.
- برای Codespaces موجود: git pull --ff-only && bash .devcontainer/update-moodle.sh

## نسخه ۰.۴ — کتابخانه پوشه‌ای و پلیر
فقط فایل‌هایی را وارد کنید که شرکت مجوز پخش و دانلود سازمانی آن‌ها را دارد.
- پیش‌فرض: پوشه `courses/` کنار compose.yaml. روی ویندوز برای استفاده مستقیم از آرشیو موجود، در فایل محلی .env خط `COURSES_DIR=E:/G-HamyarMetreh` را تنظیم کنید (مسیر نمونه؛ از / استفاده شود). پوشه باید برای Docker Desktop قابل خواندن باشد.
- هر پوشه سطح اول یک دوره واقعی Moodle؛ زیرپوشه‌ها فصل‌ها؛ فایل‌های شماره‌دار به ترتیب طبیعی و فصل‌ها به ترتیب شماره اولین ویدیو؛ جزوه‌های PDF و سایر پیوست‌های مجاز در همان کتابخانه.
- فایل‌ها در مسیر read-only می‌مانند، در GitHub و لایه Docker ذخیره نمی‌شوند. ابتدا کپی را خارج از کتابخانه کامل و سپس پوشه را منتقل کنید. همگام‌سازی هر ۵ دقیقه یا از مدیریت > ورود خودکار دوره‌ها. فایل‌های با تغییر کمتر از ۲ دقیقه نادیده گرفته می‌شوند؛ این شرط تضمین اتمام کپی نیست.
- دوره‌ها قابل مشاهده در کاتالوگ هستند، دسترسی رسانه فقط برای عضو فعال یا مدیر دارای مجوز و از طریق روش‌های ثبت‌نام استاندارد Moodle است. حذف یا تغییر نام پوشه، دوره قبلی را خودکار حذف نمی‌کند؛ تغییر نام به عنوان دوره جدید شناسایی می‌شود.
- پخش HTML5، دانلود هر فایل، PDF در مرورگر، جست‌وجوی جلسات، سرعت پخش، رفتن به عقب/جلو، ذخیره موقعیت و تخمین درصد بازه‌های پخش‌شده. ۹۵٪ برای برچسب مشاهده‌شده به کار رفته، هیچ قفلی ایجاد نمی‌کند. در صورت تغییر اندازه یا تاریخ فایل، شناسه و سابقه آن فایل عوض می‌شود. ثبت مرورگر اثبات توجه یا حضور نیست.
- MP4 با کدک H.264/AAC پیشنهاد می‌شود. MKV و فایل‌های ناسازگار قابل دانلود هستند. فایل‌های رسانه داخل بکاپ Moodle نیستند؛ آرشیو پوشه‌ای را جداگانه پشتیبان بگیرید.
- نصب موجود به علت اضافه شدن mount نیاز به یک بازسازی دارد: `git pull --ff-only && docker compose up -d --build`. از حذف volume استفاده نکنید. ابتدا بکاپ بگیرید. برای Codespaces فقط فایل نمونه و مجاز کوچک استفاده کنید.

## نسخه ۰.۵ — کتابخانه عمومی
- هر پوشه سطح اول با هر نام یک دوره؛ زیرپوشه‌ها فصل‌ها هستند. برای تبدیل پوشه به گروه چند دوره، یک فایل خالی با نام .seavan-category داخل آن بگذارید. پوشه دارای .seavan-ignore شناسایی و نمایش داده نمی‌شود.
- شماره‌های فارسی، عربی و انگلیسی در مرتب‌سازی و جست‌وجو پشتیبانی می‌شوند. ویدیو، صوت، PDF، آفیس، DWG/DXF، IFC/RVT، تصاویر و فایل‌های فشرده از پسوندهای مجاز هستند. سازگاری پخش به کدک مرورگر بستگی دارد؛ فایل‌های دیگر قابل دانلودند.
- در مدیریت کتابخانه، قبل از ساخت دوره‌های بعدی نوع عضویت را تعیین کنید: تخصیص دستی (پیش‌فرض) یا خودثبت‌نام همکاران. این گزینه دوره‌های قبلی را تغییر نمی‌دهد.
- ابتدا کپی را خارج از کتابخانه یا در پوشه دارای نشانگر ignore کامل کنید. تغییر نام پوشه به عنوان دوره جدید شناسایی می‌شود. اگر دوره در Moodle حذف شود اما پوشه بماند، دوباره وارد می‌شود؛ ابتدا پوشه را با نشانگر ignore کنار بگذارید. هیچ فایل اصلی یا دوره قدیمی به‌طور خودکار حذف نمی‌شود.
- کش کوتاه فهرست فایل‌ها و اعتبارسنجی مجدد مسیر و مشخصات فایل در زمان پخش؛ نمایش بازه‌های پخش‌شده، فیلتر وضعیت جلسات، ادامه یادگیری و رفتن اختیاری به جلسه بعدی.
- CI باید ثابت کند فایل‌های اصلی Moodle نسبت به کامیت واردسازی رسمی تغییر نکرده‌اند و آزمون چند دوره مستقل اجرا شود. قبل از بهره‌برداری منتظر تأیید موفقیت تست باشید.

## نسخه ۰.۶ — یکپارچه با صفحات اصلی Moodle
صفحه‌های واقعی /my/index.php، /my/courses.php، /course/index.php و /course/view.php تغییر کرده‌اند. صفحه خانه، کتابخانه و دوره‌های من مستقیماً در خود Moodle نمایش داده می‌شوند؛ دوره‌های پوشه‌ای در حالت عادی به پلیر آموزشی می‌روند. برای امکانات کامل، لینک «امکانات کامل دوره» یا پارامتر classic=1 در دسترس است.
اجزای داخلی سیوان همراه سورس و دیتابیس نصب می‌شوند؛ نصب افزونه توسط کاربر لازم نیست. از حذف این اجزا خودداری کنید چون تاریخچه پخش و همگام‌سازی پوشه‌ها را نگه می‌دارند.
در Codespaces نصب موجود، از git pull --ff-only و سپس bash .devcontainer/update-moodle.sh استفاده کنید. اسکریپت قبل از تغییر سرویس، تصویر جدید را می‌سازد و سپس نسخه پشتیبان محلی دیتابیس و Moodledata را در backups/ می‌گیرد. آرشیو اصلی دوره‌ها جداست. هیچ volume حذف نمی‌شود.
تغییر مستقیم صفحات هسته یعنی هنگام ارتقای نسخه رسمی Moodle باید این چهار تغییر دوباره تطبیق داده شوند. تست CI مسیرهای جدید را بررسی می‌کند؛ نتیجه موفق باید قبل از استقرار واقعی تأیید شود.

## نسخه ۰.۷ — رابط یکپارچه و خلوت
- فقط یک منو در صفحات آموزشی: خانه، کتابخانه، دوره‌های من و مدیریت (با مجوز). قالب فضای آموزشی بدون کشوهای تکراری است؛ فرم ورود، نشست، منوی حساب و داده‌ها همچنان واقعی Moodle هستند.
- خانه: خوشامد کوتاه، ادامه آخرین جلسه و کارت آموزش‌ها. مدیریت: سه گروه محتوا، کاربران و گزارش/تنظیمات. امکانات پیشرفته در بخش بازشونده قرار دارند.
- پلیر: ویدیو، فهرست فصل‌ها، وضعیت جلسات و دانلود، با یک استایل یکدست. ظاهر مدیریتی اصلی Moodle برای صفحات پیشرفته باقی است.
- برای نصب آزمایشی موجود: `git pull --ff-only && bash .devcontainer/update-moodle.sh`. این به‌روزرسانی یک بکاپ محلی می‌گیرد؛ نسخه در حال اجرا تا زمان اجرای آن تغییر نمی‌کند.

## نسخه ۰.۸ — پلیر آماده و جست‌وجوی جلسات
- از Video.js 8.17.3 همراه Moodle 4.5 استفاده می‌شود، بدون CDN و نصب دستی. کنترل سرعت، تمام‌صفحه، کلیدهای میانبر، پرش زمانی و ترجمه فارسی از کتابخانه موجود می‌آیند. تاریخچه مشاهده همچنان در دیتابیس سیوان ثبت می‌شود. اگر پلیر بارگذاری نشود، کنترل‌های مرورگر جایگزین می‌شوند؛ لینک «پلیر ساده» نیز برای انتخاب دستی وجود دارد.
- فایل زیرنویس WebVTT را کنار ویدیو با نام یکسان قرار دهید: Lesson.mp4 و Lesson.fa.vtt یا Lesson.en.vtt. زیرنویس با مجوز دوره از همان سرور ارائه می‌شود. SRT فعلاً فقط دانلود می‌شود.
- جست‌وجوی کتابخانه علاوه بر نام دوره، نام جلسات و پیوست‌های دوره‌های مجاز را بررسی می‌کند؛ حداکثر ۶۰ نتیجه. برای نمایش نتایج بیشتر، عبارت دقیق‌تر وارد کنید.
- فرمت قابل پخش به کدک مرورگر وابسته است؛ Video.js تبدیل‌کننده ویدیو نیست. برای MP4 کدک H.264/AAC و برای WebM کدک VP8/VP9 پیشنهاد می‌شود.
- تست مرورگر Chromium با Playwright به CI اضافه شده: ورود، جست‌وجوی جلسه، پخش WebM نمونه، زیرنویس، ثبت پیشرفت و حالت ساده. نتیجه موفق این تست باید پیش از استقرار تأیید شود.

## نسخه ۰.۹ — امکانات تکمیلی
- FFprobe/FFmpeg در تصویر اصلی: هر ۱۰ دقیقه حداکثر ۱۲ فایل جدید بررسی می‌شوند. مدت، کدک و کاور استخراج‌شده در Moodledata نگهداری می‌شوند؛ فایل اصلی فقط خواندنی است. تشخیص سازگاری تقریبی است و سلامت کل فریم‌ها را تضمین نمی‌کند.
- مدیریت > سلامت کتابخانه: وضعیت آماده/در انتظار/خطا و درخواست تبدیل اختیاری به H.264/AAC. پردازشگر مستقل هر بار یک فیلم را تبدیل می‌کند؛ نسخه اصلی برای دانلود می‌ماند.
- «دانلود دوره» در پلیر، دانلود فایل تکی، فصل، چند فایل انتخابی و کل دوره را ارائه می‌کند. بسته‌های چندبخشی برای دوره‌های بزرگ به‌صورت ZIP مستقل ساخته می‌شوند. هر ZIP تا ۲۰ گیبی‌بایت است و فضای موقت کافی لازم دارد.
- علاقه‌مندی دوره، فیلتر علاقه‌مندی‌ها، یک یادداشت خصوصی تا ۴۰۰ نویسه و یک نشانک زمانی قابل ویرایش برای هر فایل. یادداشت‌ها در تنظیمات کاربری Moodle ذخیره می‌شوند.
- Whisper اختیاری: WHISPER.cmd یا docker compose --profile whisper up -d --build whisper. مدل چندزبانه small با CPU/int8، بارگیری اولیه نیازمند اینترنت است؛ صوت روی سرور پردازش می‌شود. در سلامت کتابخانه، فایل را جست‌وجو و «تولید متن» را انتخاب کنید. متن تولیدشده در پلیر و جست‌وجوی کتابخانه قابل جست‌وجو و رفتن به زمان نتیجه است؛ تشخیص گفتار خطاپذیر است.
- گزارش خلاصه استفاده در مدیریت. درصد مشاهده تخمین بازه‌های پخش است، نه اثبات توجه.
- START.cmd: پیش‌نیاز Docker Desktop فعال و Git برای دریافت/به‌روزرسانی ریپو. در اولین اجرا مسیر آرشیو و IP انتخاب می‌شود. BACKUP.cmd، UPDATE.cmd، RESTORE.cmd و WHISPER.cmd برای نگهداری. بکاپ شامل دیتابیس، Moodledata و تنظیمات خصوصی است؛ آرشیو اصلی و مدل قابل دانلود Whisper جداگانه نگهداری شوند. بازیابی فقط از بکاپ قابل اعتماد خودتان و با .env مطابق و تایید RESTORE انجام شود؛ قبل از بازیابی بکاپ تازه می‌گیرد. فایل‌های بکاپ حاوی اطلاعات شخصی و رمزهای سرور هستند؛ منتشر نکنید.
- صفحه موبایل: فیلم در اولویت، ابزارهای اضافی در بخش بازشونده؛ تست مرورگر در عرض ۳۹۰ پیکسل اضافه شده. هیچ تضمین اجرای موفق روی گوشی یا ویندوز قبل از تست واقعی وجود ندارد.

## نسخه ۱٫۰ — تحویل سازمانی
راهنمای فارسی نصب، HTTPS، مدیریت آرشیو، بکاپ و آزمون پذیرش: [docs/company-fa.md](docs/company-fa.md). آزمون پذیرش روی سرور و شبکه مقصد در همین راهنما آمده است.

## RC6 — بازیابی ورود Codespaces
برای محیط آزمایشی موجود و خصوصی پورت 8081 فقط: پس از دریافت شاخه release/v1-company، `bash .devcontainer/recover-preview.sh` را اجرا کنید. این دستور آدرس فعلی Codespace را تنظیم می‌کند، بکاپ می‌گیرد، نسخه را به‌روز می‌کند، رمز موقت قوی مدیر موجود را ایجاد می‌کند و ورود واقعی به صفحه مدیریت را از طریق شبیه‌سازی لایه HTTPS proxy می‌سنجد. رمز در `.env` خصوصی ذخیره می‌شود. هیچ داده‌ای حذف نمی‌شود. در صورت شکست، خروجی خطا را بررسی کنید. این آزمون جایگزین تست مرورگر از مسیر واقعی GitHub forwarding نیست. از انتشار عمومی پورت آزمایشی خودداری کنید.
