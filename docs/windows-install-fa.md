# نصب آکادمی سیوان ۱٫۱ روی ویندوز

۱. Docker Desktop را با WSL 2 و حالت Linux containers فعال کنید. نصب اول برای ساخت سرویس‌ها به اینترنت نیاز دارد.
۲. فایل ZIP را در یک پوشه کوتاه روی درایو NTFS، مثلاً C:\SeavanAcademy، استخراج کنید و START.cmd را دوبار کلیک کنید.
۳. ایمیل واقعی مدیر را وارد کنید. برای آزمایش می‌توانید این فیلد را خالی بگذارید. مسیر پوشه دوره‌های موجود را وارد کنید یا برای استفاده از پوشه courses این فیلد را خالی بگذارید.
۴. در نشانی http://127.0.0.1:8080 با نام کاربری admin و رمز موقت admin وارد شوید. Moodle همان‌جا تغییر رمز را اجباری می‌کند. رمز جدید حداقل ۱۲ نویسه داشته باشد.
۵. هر پوشه سطح اول آرشیو یک دوره و زیرپوشه‌های آن فصل‌اند. از مدیریت ← ورود خودکار دوره‌ها همگام‌سازی را اجرا کنید. از مدیریت آرشیو ← ثبت‌نام و دسترسی کاربران، کارکنان مجاز هر دوره را تعیین کنید.

## آزمون‌ها و گزارش تماشا

- از پلیر دوره، «آزمون‌های دوره» را باز کنید. مدیر از «افزودن آزمون» وارد فرم اصلی آزمون Moodle می‌شود و سؤال‌ها، زمان و نمره را همان‌جا تعیین می‌کند.
- در مدیریت ← گزارش تماشای افراد، نام دوره را بزنید تا مدت مشاهده، درصد پوشش و آخرین فعالیت هر فرد برای هر جلسه نمایش داده شود. یک بازه تکراری دوباره به مدت مشاهده اضافه نمی‌شود.
- گزارش از بازه‌های پخش ثبت‌شده در پلیر ساخته می‌شود. زمان نشستن پشت سیستم و توجه فرد را اندازه نمی‌گیرد.

## حساب‌ها و ویدیو

- ثبت‌نام عمومی غیرفعال است. Moodle رمزها را هش می‌کند. رمز کاربران را در فایل اشتراکی نگه ندارید. در مسیر اکسل آکادمی، ستون password پذیرفته نمی‌شود.
- در نسخه نصبی، دانلود فایل و ZIP از مسیر آکادمی حتی برای مدیر بسته است. لینک پخش به نشست خود کاربر وابسته است. دانلود عادی در پلیر و منوی راست‌کلیک محدود شده و روی ویدیو نام کاربر نمایش داده می‌شود.
- فیلم‌ها را از مسیر آرشیو آکادمی ارائه کنید. قرار دادن مستقیم ویدیو در مخزن فایل عمومی یا فعالیت فایل Moodle مسیر متفاوتی برای دسترسی می‌سازد.
- پخش در مرورگر معمولی همچنان امکان ضبط صفحه یا ذخیره جریان با ابزار تخصصی را به‌طور قطعی از بین نمی‌برد.
- برای استفاده از لپ‌تاپ‌های دیگر، ابتدا رمز موقت را تغییر دهید و سپس HTTPS داخلی مورد اعتماد را طبق راهنمای شرکت فعال کنید. فایل .env، داده‌های Docker و آرشیو را فقط در اختیار مسئول سرور بگذارید.

## نگهداری

- START.cmd روی پوشه نصب موجود، نشست قبلی یا رمز تعویض‌شده را بازنشانی نمی‌کند.
- BACKUP.cmd و RESTORE.cmd را همراه RELEASE-COMMIT در پوشه نصب نگه دارید. بازیابی بسته ZIP برای همان نسخه پشتیبان در دسترس است. برای بازگشت بین نسخه‌ها چک‌اوت Git لازم است.
- در صورت خطای شروع، DIAGNOSE.cmd را اجرا کنید. برای جزئیات شبکه داخلی، آرشیو و پشتیبان‌گیری به company-fa.md مراجعه کنید.
